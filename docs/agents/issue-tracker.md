# Issue tracker: GitHub

Specs and tickets live in this repository's GitHub Issues. Infer the repository from
the Git remote. Use `gh` or the connected GitHub tools to read and publish issues.

When a skill says to publish to the issue tracker, create a GitHub issue. For
multiline bodies with `gh`, write the body to a file and use `--body-file`.

Triage is not used. Omit triage steps and labels, including `ready-for-agent`, when
following engineering skills.

PRs as a request surface: no.
