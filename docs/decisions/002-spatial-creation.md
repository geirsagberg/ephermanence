# Create spatial thoughts in place

Status: accepted — 4 August 2026

Double-clicking empty space opens a bubble-shaped text editor at that position. Plain
Enter keeps the thought, Shift+Enter inserts a line break, and Escape cancels.

This keeps spatial creation direct and consistent with the bubble interaction model.
The docked composer and full capture-sheet alternatives added unnecessary distance
between the chosen location and the thought being written.

The complete comparison remains available on the
`prototype/spatial-capture-variants` branch at commit `8b7c7e9`.
